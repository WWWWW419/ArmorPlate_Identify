
基于 C++ / OpenCV 的前哨站装甲板检测程序：输入一张图片，自动完成颜色分割、
灯条候选提取、灯条配对，输出装甲板候选的外接框、中心点和有序四角点。

## 环境要求:
 编译器  MinGW-w64 GCC 16.2.0（UCRT） 
 CMake  4.4.2 
 OpenCV  4.12.0


项目根目录的 "opencv/" 下"CMakeLists.txt" 会自动查找"opencv/x64/mingw/lib/OpenCVConfig.cmake"


## 算法流程:

输入图
  ↓ cvtColor → HSV / GRAY
  ↓ inRange（红色两段合并）+ 灰度阈值 → 颜色 mask
  ↓ morphologyEx（先闭后开）→ 清理 mask
  ↓ findContours → 轮廓
  ↓ 面积 / 细长比 / 尺寸 筛选 → 灯条候选
  ↓ 两两配对（6 项几何检查）→ 候选组合
  ↓ 唯一匹配 + 中心去重 → 装甲板
  ↓ 四角点 + 中心点 + 外接框



## 参数依据：本图灯条因过曝，实测色相漂移到 H≈13~22，因此上限放宽到 32，否则右侧灯条会漏检。

## 灯条筛选:
  条件1：轮廓面积>60，排除噪点
  条件2：短边>=3像素，排除minAreaRect退化结果
  条件3: 短边/长边 < 0.8，排除方块状误检

## 灯条配对：
  比对以下六项
  1.颜色类别(BarColor)必须相同
  2.色相一致(色相环距 + 饱和度差共同检测)
  3.长度相近
  4.方向协调(比对长轴夹角)
  5.上下偏差(比对沿长轴投影长度/平均长)
  6.间距比例
  通过后按加权分数排序，用唯一匹配 + 中心距离去重保证同一块装甲板只输出一次。
  全部用相对比例比较

四角点顺序约定为左上(0) -> 右上(1) -> 右下(2) -> 左下(3)
      生成方式：以两条灯条中心的连线为基准，统一长轴方向指向图像上方后，

## 参数调整

所有可调参数集中在 `LampColorRange` 结构体（`ImageProcess.h`）：

| 参数               | 默认值                       | 含义                     |
| `redLow1/redHigh1` | (0,45,55) ~ (32,255,255)    | 红色第一段（含过曝偏橙）   |
| `redLow2/redHigh2` | (160,45,55) ~ (179,255,255) | 红色第二段                |
| `blueLow/blueHigh` | (100,45,55) ~ (130,255,255) | 蓝色范围                  |
| `grayMin`          | 55                          | 灰度亮度下限（0=不约束）   |
| `morphCloseSize`   | 5                           | 闭运算核（0=不做）        |
| `morphOpenSize`    | 3                           | 开运算核（0=不做）        |

灯条与配对的阈值在 `CollectBars` / `EvaluatePair` 中集中定义。

## 问题记录

### 问题 1：mask 中灯条内部有空洞、形状弯曲

- **出现步骤**：颜色分割
- **原因**：灯条是强光源，中心过曝导致饱和度 S 下降，`inRange` 只选中了中间一条带
- **修改**：S 下限 80 → 45，V 下限 70 → 55；加 5×5 闭运算填补空洞
- **结果**：灯条变为实心白条，`minAreaRect` 拟合明显更准
- **副作用**：背景略微变脏，靠后续的面积和长宽比筛选挡住

### 问题 2：左侧货架上的橙色杂物被误检为灯条

- **出现步骤**：轮廓筛选
- **原因**：颜色完全相同，仅靠 HSV 无法区分
- **修改**：加入细长比 < 0.80 和「高 > 宽」的竖条判断
- **结果**：杂物被排除
- **副作用**：目标旋转到接近水平时可能被误杀（本阶段未处理）

### 问题 3：侧向时四角点绿框不贴合灯条

- **出现步骤**：四角点计算
- **原因**：原先用「4 个顶点投影分组再平均」，灯条较短时分类失败，兜底退化成中心点
- **修改**：改为 `中心 ± 长轴单位向量 × 半长` 直接解析求端点
- **结果**：绿框贴合度明显提升，倾斜情况下也稳定

### 问题 4：红色灯条在色相接缝处漏检

- **出现步骤**：颜色分割
- **原因**：H 是环形，红色跨越 0/179 边界
- **修改**：拆成两段 `inRange` 后用 `bitwise_or` 合并
- **结果**：红色目标完整检出

## 异常测试

| 测试 | 方法 | 结果 |
|---|---|---|
| 图片路径不存在 | 把文件名改为 `not_exist.png` | 打印 `Read failed`，返回 -1，未崩溃 |
| 检测不到目标 | 把 S 下限调到 250 | 输出 0 个候选，正常结束 |
